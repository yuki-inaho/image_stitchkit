# 論文・参照実装と対応範囲

## 対象の整理

利用者の最初の2手法を、添付内容に基づいて次のように扱っています。

1. `Parallax-Tolerant-Image-Stitching-master.zip`: Robust Elastic Warping (REW)。
2. `NISwGSP-master.zip`: Natural Image Stitching with the Global Similarity Prior。
3. 追加指定: Geometric Structure Preserving Warp for Natural Image Stitching (GES-GSP)。

GPU 版 NISwGSP の添付は構成の参照と VLFeat の取得元です。
`DIP_Final_Project-master.zip` は別の Parallax-tolerant 手法の学習用実装であり、
その手法を REW と同一視していません。今回は実画像の試験資料として利用しています。
LINEAE の記事は線分検出の追加指定として扱い、第4の合成モードにはしていません。

これは数式と公開実装の読解に基づく独立実装です。PDF全文をすべて取得できたわけではなく、
著者バイナリとの数値照合、論文の評価表の再現、全パラメーターの一致確認は行っていません。
以下の差分を含むため、論文そのものの厳密再現版とは区別してください。

## 共通の対応点推定

VLFeat SIFT、RootSIFT 正規化、双方向の最近傍比率検査を使用します。
RANSAC で初期のホモグラフィを推定し、残りの対応点にも最大3回のモデル検証を行って、
奥行きの異なる領域の対応を単一平面の外れ値としてすべて捨てないようにしています。
これは本実装の共通化した検証方式で、参照実装の特徴点選択・全閾値をそのまま再現したものではありません。

入力は順序付きの隣接接続です。初期ホモグラフィと相似変換を合成して第0画像の座標系へ置きます。
NIS/GES はその後に全入力メッシュを同時に最適化し、中間の合成画像を再入力して繰り返し補間しません。

## REW

`src/rew.cpp` に実装しています。対応は、元画像 s から参照画像 t への
ホモグラフィ H とします。参照画像上の点 p の元画像への予測は q=H^{-1}p です。
制御点 q_i=H^{-1}p_i、残差 r_i=q_i-s_i から TPS を求めます。

```
U(r) = 0.5 r² log(r²),  U(0) = 0
[K + λ·8π I, P; Pᵀ, 0] [w; a] = [r; 0]
f(q) = Σ w_i U(||q-q_i||) + a_0 + a_x q_x + a_y q_y
W⁻¹(p) = H⁻¹p − η(H⁻¹p) f(H⁻¹p)
```

座標を画像対角長で正規化し、平滑化項も対応するスケールで変換します。
重複制御点の排除、空間的に分散した制御点への上限設定、係数の3標準偏差による反復除外、
重複領域の外側での減衰を実装しています。変位ゼロでも減衰幅がゼロにならないようにしています。

差分は、制御点の既定上限384、最遠点選択による間引き、8画素格子での逆写像評価、
複数画像時の隣接逆写像合成です。元の複数視点最適化・継ぎ目最適化の代替ではありません。
外枠は初期ホモグラフィの角と変位に基づく余白から決めます。すべての局所極値を
解析して外枠を最小化するものではありません。TPS の全域で単射性を証明する検査もありません。

`alignment_rmse` は各組の元画像座標での制御点残差です。
そのため NIS/GES の共通パノラマ座標での残差と、そのまま同じ尺度の順位比較には使えません。

## NISwGSP

`src/mesh_warp.cpp` に実装しています。各画像の格子頂点 v を未知数として、
対応点 p の変形を4頂点の双線形補間 B(p)v で表します。

```
E = ||w_a A_alignment v||²
  + ||w_l A_local v||²
  + ||W_g (A_global v − s_global)||²
```

対応点項は、対応する2画像の補間結果を一致させます。
局所項は各辺の周辺頂点から最小二乗で求めた相似変換と、その辺の変位との整合性です。
全体項は、その局所的な相似変換の係数を、各画像の相似変換事前分布に近づけます。
重みは β+γd とし、d は特徴対応までの距離を対角長で正規化した値です。
距離の算出は参照実装のセル単位の距離伝播ではなく、最寄りの対応点までの距離です。

辺の周辺差分行列を E、疑似逆を G=(EᵀE)⁻¹Eᵀ、辺の行列を M_e とすると、
局所残差は `(v_b-v_a) − M_e G(v_neighbors-v_a)`、
全体残差は `G(v_neighbors-v_a) − [scale cosθ, scale sinθ]` です。
本実装では `[a,-b;b,a]` の通常の相似変換の符号規約へ統一しています。

移動重み付き DLT (APAP) によるメッシュ頂点の対応も追加します。
`max(0.0015, exp(-distance²/sigma²))` を用い、対応点が存在する矩形領域の内部に限定します。
元の APAP の全グラフ探索・評価設定と一致するわけではありません。

相似変換は2次元のみです。3次元カメラ姿勢、焦点距離、バンドル調整、回転の最適化はありません。
第0画像の最初の頂点へ2本の平行移動アンカーを入れ、縮退を除去します。
Eigen SparseQR で倍精度の最小二乗系を解き、階数と正常方程式の残差を検査します。
著者実装の反復法と同じ数値経路ではありません。

## GES-GSP

NIS のメッシュ系に、直線・曲線の標本に対する三角形の相似性保存項を追加します。
構造の2標本 a,b を基準に各標本 p を表し、変形後もその座標関係を維持します。

```
u = dot(p-a,b-a) / ||b-a||²
v = cross(b-a,p-a) / ||b-a||²
p' − a' − u(b'−a') − v R90(b'−a') = 0
```

x と y を結合した2本の行として実装します。v=0 の直線だけでなく、v≠0 の曲線標本も保持します。
閉曲線で最初と最後が近い場合にも退化しないよう、最も離れた標本対を基準にします。

標準の構造抽出は、Sobel 勾配、非極大抑制、輪郭追跡、長さによる選別と標本化です。
長すぎる輪郭は分割し、勾配強度を簡易な信頼度として使用します。
これは著者実装の構造抽出・顕著度計算・標本ごとの重みの完全な移植ではありません。
LINEAE を選んだ場合は信頼度の高い線分を最大枠の半分まで入れ、残りへ輪郭を補充します。
この併用方式も本プロジェクト独自の構成です。

構造重みを上げると、構造を保つ代わりに対応点誤差が増える場合があります。
試験は「対応点誤差が常に最小になる」ことではなく、追加した幾何項が実際に
曲線・直線の相似性残差を低減することを検証します。

## 合成と未対応部分

全モード共通で双線形の逆写像標本化と境界距離による加重合成を行います。
グラフカットの継ぎ目、多重解像度合成、露出補正、動体除去は含みません。
これらがないため、視差や遮蔽を伴う画像のすべてで継ぎ目・二重像が消える保証はありません。
入力列が長い場合の全体ドリフトや、順序を持たない画像集合も本実装の評価範囲外です。
